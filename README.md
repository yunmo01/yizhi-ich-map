# 指尖上的非遗 · 国家级非遗代表性传承人数据图谱

为文化保护工作者与社会公众，提供传承人地域、门类、代际分布的全景视角。

## 在线体验

打开部署地址 **https://yunmo01.github.io/yizhi-ich-map/** 即可使用全部功能（纯静态、无需安装、离线数据内置）：
首页 → 数据图谱（九视图联动 · 地图点击下钻 · 多维筛选）→ 资料查询（全文检索 · 官网溯源）。

## 数据

- 来源：中国非物质文化遗产网（ihchina.cn）国家级代表性项目 / 传承人公开清单及官方简介
- 规模：3995 位传承人 · 3610 项目子项 · 34 省级行政区 · 十大门类 · 六批次（2007—2025）· 6663 条官方简介
- 口径与官网名录一致；检索结果均附官网直达链接

## 本地运行（可选）

纯静态站点也可本地打开：

```
python -m http.server 8000
# 浏览器访问 http://127.0.0.1:8000
```

## 技术

Apache ECharts + 原生 JavaScript；数据本地聚合（无后端依赖）。
